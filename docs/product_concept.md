# プロダクトコンセプト仕様書

## 1. サービス概要
- **サービス名称（仮）**: こころ寄り添いアニメ処方箋（Mental Anime Concierge）
- **タグライン**: 「落ち込んだ夜、親身な友達が選んでくれる、傷つかないアニメ提案」

## 2. 存在意義と課題解決
### 課題
1. **既存レコメンドの限界**:
   - アルゴリズム推薦（「あなたへのおすすめ」）は人気作やジャンル軸であり、「今の心の脆さ」を考慮しない。
   - 「元気が出るアニメ」で検索しても、作中で過酷な挫折・パワハラ・いじめ・死別などの地雷描写が含まれ、かえって精神的ダメージを受ける事故が多発する。
2. **選択疲労（Decision Fatigue）**:
   - 弱っているときは長文検索やレビューの精査、VODの横断検索をする気力がない。
3. **商業的誘導への不信**:
   - 安易な「初月無料体験」への誘導や、高額なプレミア価格の中古購入リスクなど、ユーザーの生活キャパシティを無視した案内が多い。

### 存在意義・コアバリュー
1. **心の安全第一（地雷トリガーの完全回避）**:
   - ユーザーのストレス原因に直結するトラウマ描写を厳格にフィルタリング。
2. **文脈重視のコンテンツ処方**:
   - 気分・エネルギー残量（HP）・受け止めてほしいトーンに寄り添った作品選定。
3. **誠実で現実的な視聴案内（友達目線）**:
   - 契約中VODを最優先。未契約配信やプレミア高騰品には「解約忘れ注意」「高すぎるから買っちゃダメ」とブレーキをかける親友目線。

## 3. 主要ターゲットペルソナ
- **社会人（20代〜30代）**:
   - 仕事の人間関係やプレッシャーで帰宅後に精神的HPが残り5%の状態。
   - 何か観て癒やされたいが、重い展開や説教くさいものは一切受け付けない。
- **学生・就活生**:
   - 将来への不安や自己肯定感の低下、人間関係の行き詰まりを感じている。
   - 共感と肯定、あるいは現実逃避できる世界観を求めている。
- **原因不明の虚無感・不眠を抱える人**:
   - 理由もなく涙が出る、寝付けない、静かに心を鎮めたい。
